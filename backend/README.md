# SafeDoc Generator — Backend

Simple Node.js + Express backend for SafeDoc Generator.

Setup

1. Change to the backend folder:

```bash
cd backend
```

2. Install dependencies:

```bash
npm install
```

3. Copy `.env.example` to `.env` and adjust values if needed.

Run

```bash
npm run dev
```

Test route

- `GET /api/health` — returns a simple health JSON payload.
